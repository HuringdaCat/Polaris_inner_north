## Information Collection and Use

The Application collects information when you download and use it. This information may include the following:

*   **User Provided Information:** The Application obtains the information you provide when you interact with the AI features.
*   **AI Interactions (OpenAI):** When you use features powered by artificial intelligence (e.g., chat, reflection analysis), the text data you input is sent to OpenAI's API for processing. This data is not used by the Service Provider to train models, but is subject to OpenAI's data usage policies.

The Application does **not** collect precise information about the location of your mobile device.
